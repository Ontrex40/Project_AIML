## AI and Machine Learning Project — 2025–2026
## Bilal Mohammed & Giuseppe De Iesu

This project focuses on **house price prediction** using both **regression** and **classification** techniques.

- Multiple Linear Regression implemented **from scratch**
  - Normal Equation
  - Gradient Descent
- Statistical **hypothesis testing** on regression coefficients
- Binary classification of prices (high / low)
  - K-Nearest Neighbors
  - Logistic Regression

The workflow includes data cleaning, exploratory data analysis, PCA, model evaluation, and diagnostic plots.
